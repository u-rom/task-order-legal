Task Order プライバシーポリシー

最終更新日: 2026年7月10日
お問い合わせ: yuya007007@gmail.com

1. はじめに

Task Order（以下「本アプリ」）は、個人のタスク管理・ポモドーロ・学習マップを支援する iOS アプリです。本ポリシーは、本アプリが扱うデータの種類、保存場所、外部送信の有無を説明します。

2. 収集・保存するデータ（端末内）

本アプリはアカウント登録を行いません。以下のデータは端末内の SQLite データベースに保存され、開発者のサーバーへ自動同期されることはありません（AI 機能を除く）。

データ内容保存場所
タスクタイトル、コメント、完了状態、並び順端末内
ポモドーロセッション記録、作業時間設定端末内
ワールド / マップステージ名、進捗、マップ設定端末内
バッジ・称号獲得バッジ、候補、おすすめ能力端末内
アプリ設定通知音、画面点灯、AI 同意記録など端末内
installationId端末ごとに生成される UUID（利用回数制限・課金識別用）端末内

端末の iCloud バックアップ等の対象になる場合があります。これは Apple の OS 機能に依存します。

3. AI 機能利用時に外部送信されるデータ

バッジ再計算・おすすめ能力の生成など AI 機能を利用した場合に限り、タスク名・コメント・ワールド名・バッジ名等のテキストがインターネット経由で外部サービスへ送信されます。

意図的に送信しない情報: 氏名、メールアドレス、電話番号、位置情報、連絡先、写真など個人を特定する情報。

送信先

  • Amazon Web Services（AWS） — リージョン ap-northeast-1（東京）。API Gateway / Lambda 上の自前バックエンド。
  • Anthropic PBC — Claude API（商用 API）。バックエンドから AI 解析のため送信。

モデル学習への利用

Anthropic の商用 API を利用しているため、送信内容が Claude モデルの学習に使われることはありません。

データの保持

Anthropic 側では不正利用監視等のため、API 経由のデータが最大 30 日程度保持される場合があります。

installationId

乱用防止のため、端末ごとに生成した UUID を API リクエストに含めます。これ単体では個人を特定できません。prod 環境では AI 利用上限の判定のため、同一 ID をサーバーから RevenueCat へ問い合わせる場合があります。

4. アプリ内課金（App Store / RevenueCat）

App Store 版など課金機能が有効なビルドでは、次のアプリ内課金を App Store 経由で提供します。

商品形態内容
Pro（買い切り・非消耗）非消耗型 IAP2枠目以降のワールド枠・マップ演出・バッジ演出などを永久に解放
AIチケット消耗型 IAPAI 再計算枠の追加。消耗品のため復元できません
Tip（応援）消耗型 IAP開発への応援。機能解放なし。消耗品のため復元できません

決済

決済処理は Apple App Store が行います。クレジットカード番号等の支払情報は開発者のサーバーへ送信されません。

RevenueCat（RevenueCat, Inc.）

購入状態の管理のため RevenueCat SDK を利用します。

送信項目内容
App User ID端末の installationId（UUID）
購入状態StoreKit 経由のトランザクション情報
端末・SDK 情報RevenueCat サービス提供に必要な技術情報

意図的に送らない情報: タスク内容、氏名、メール、電話、位置情報、写真。

RevenueCat プライバシーポリシー: https://www.revenuecat.com/privacy

サーバー側の購入確認（prod）

AI 利用上限のため、prod の AWS Lambda が RevenueCat API で installationId に紐づく購入状態を確認する場合があります。ログには installationId 全文ではなく prefix のみを記録します。

購入の復元

  • Pro（非消耗）: アプリ内の「購入情報を復元」から復元できます。
  • AIチケット / Tip（消耗）: 消耗品のため復元できません。

5. その他の第三者サービス（分析・広告）

現行 V1 では PostHog・Google Analytics・広告 SDK は組み込んでいません。将来導入する場合は本ポリシーを更新し、アプリ内で告知します。

6. データの削除

  • 端末内: アプリ削除で OS の仕様に従い削除されます。
  • AI データ: 個別削除要求はお問い合わせ先まで（Anthropic のポリシーに依存）。
  • 課金データ: 購入履歴は Apple / RevenueCat 側に保持されます。

7. セキュリティ

Anthropic API キーはアプリに埋め込みません。通信は HTTPS を使用します。

8. お子様の利用

本アプリは 13 歳未満を対象としたサービスではありません。

9. ポリシーの変更

内容を変更する場合は本ページの最終更新日を更新し、重要な変更はアプリ内で告知します。
