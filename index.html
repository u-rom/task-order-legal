Task Order プライバシーポリシー

最終更新日: 2026年10月25日
お問い合わせ: yuya007007@gmail.com

1. はじめに

Task Order（以下「本アプリ」）は、個人のタスク管理・ポモドーロ・学習マップを支援する iOS アプリです。本ポリシーは、本アプリが扱うデータの種類、保存場所、外部送信の有無を説明します。

2. 収集・保存するデータ（端末内）

本アプリのタスク・ポモドーロ・記録などの機能は、アカウント登録なしで 使えます。以下のデータは 端末内の SQLite データベース に保存され、開発者のサーバーへ自動同期されることはありません（AI 機能を除く、後述）。AI 機能を使う場合に限り、AIアカウント（Sign in with Apple）でのログインが必要です（§3.1）。

データ 内容 保存場所
タスク タイトル、コメント、完了状態、並び順 端末内
ポモドーロ セッション記録、作業時間設定 端末内
ワールド / マップ ステージ名、進捗、マップ設定 端末内
バッジ・称号 獲得バッジ、候補、おすすめ能力 端末内
アプリ設定 通知音、画面点灯、AI 同意記録など 端末内
installationId 端末ごとに生成される UUID（AIアカウントへのログイン前の課金識別用） 端末内
AIアカウントのログイン情報 サーバーが発行した利用者ID、アクセス用・更新用のトークン 端末の Keychain（この端末だけに保存。バックアップや別の端末へは移りません）
反映を確認中のAIチケット購入 購入が完了したのに残数への反映を確認できていない購入の取引ID（再確認のため。AIアカウントごと、最大50件） 端末内（反映の確認、またはAIアカウントの削除で消去）

端末の iCloud バックアップや iTunes バックアップの対象になる場合があります。これは Apple の OS 機能に依存します。

3. AI 機能利用時に外部送信されるデータ

バッジ再計算・おすすめ能力の生成など AI 機能を利用した場合に限り、以下のテキストデータが インターネット経由で外部サービスへ送信 されます。

送信される項目 例
タスク名 完了タスクのタイトル
タスクコメント ポモドーロ完了時のメモ（最大 500 文字程度）
ワールド名 / ステージ名 マップ上の名称
バッジ名・キーワード 獲得済みバッジや候補の名称

意図的に送信しない情報: 氏名、メールアドレス、電話番号、位置情報、連絡先、写真など個人を特定する情報。

開発者のサーバーは、AIに送るテキストを AI の生成のために Anthropic へ中継するだけで、保存しません。サーバーに残すのは、利用回数（月ごとの無料枠の使用数・AIチケットの残数）などの記録だけです。

3.1 AIアカウント（Sign in with Apple）

AI 機能（AIの生成・AIチケットの購入）を使うときだけ、Sign in with Apple でのログインを求めます。タスク・Canvas・ポモドーロ・記録、Pro や応援の購入・復元にはログインは不要です。

項目 扱い
Apple から受け取る情報 Apple が署名した本人確認情報（Apple が発行するこのアプリ用の識別子を含む）。名前とメールアドレスは求めません
サーバーが発行する利用者ID 同じ Apple アカウントには同じ利用者IDを使い、AIの月ごとの無料枠と購入したAIチケットを管理します。端末をまたいで共有されます
AIに送るテキストとの関係 AI 機能のリクエストには利用者IDを付けて送るため、送信したテキストはサーバー上で利用者IDと結び付きます
ログイン情報の保存 アクセス用・更新用のトークンは端末の Keychain にだけ保存します。サーバーにはトークンのハッシュだけを保存します

アクセス用トークンの有効期限は15分で、期限が切れると更新用トークンで自動的に更新します。更新用トークンの有効期限は30日で、更新のたびに新しくなります。

iPhone・iPad の設定で「Appleでサインイン」の使用を停止した場合や、Apple アカウントを削除した場合は、Apple からの通知を受けてサーバー側のセッションをすべて無効にします。次にAIを使うときに、もう一度ログインが必要になります。

ログアウトすると、端末のトークンを必ず消し、サーバー側のセッションの無効化も要求します（通信できなかった場合でも端末のトークンは消え、サーバー側のセッションは、更新用トークンが使われないまま有効期限（30日）を過ぎると使えなくなります）。AIの無料枠と購入したAIチケットはサーバーに残り、同じ Apple アカウントで再ログインすると続けて使えます。

送信先

  1. Amazon Web Services（AWS） — リージョン: ap-northeast-1（東京）
    API Gateway / Lambda 上の自前バックエンドがリクエストを受け付けます。
  2. Anthropic PBC — Claude API（商用 API）
    バックエンドから AI 解析のため送信されます。

モデル学習への利用

Anthropic の 商用 API を利用しているため、送信された内容が Claude モデルの 学習（ファインチューニング）に使われることはありません（Anthropic Commercial Terms に準拠）。

データの保持

Anthropic 側では、不正利用の監視・サービス改善等のため、API 経由のデータが 最大 30 日程度 保持される場合があります。Zero Data Retention（ZDR）は現時点では未設定です。

利用者ID

AI 機能の API リクエストには、AIアカウントの利用者IDとアクセス用トークンを含めます。AIの利用回数とAIチケットの残数は、この利用者IDごとにサーバーで管理します。

App Store 版では、AIチケットの購入を確認するため、サーバーから RevenueCat（後述）へ利用者IDで購入状態を問い合わせます。

4. アプリ内課金（App Store / RevenueCat）

App Store 版など 課金機能が有効なビルド では、次のアプリ内課金を App Store 経由で提供します。

商品 形態 内容
Pro（買い切り・非消耗） 非消耗型 IAP 2枠目以降のワールド枠・マップ演出・バッジ演出などを 永久 に解放
AIチケット 消耗型 IAP AI 再計算枠の追加。消耗品のため復元できません
Tip（応援） 消耗型 IAP 開発への応援。機能解放なし。消耗品のため復元できません

決済

  • 決済処理は Apple App Store が行います。
  • クレジットカード番号等の支払情報は 開発者のサーバーへ送信されません。

RevenueCat（RevenueCat, Inc.）

購入状態（entitlement）の管理のため、RevenueCat SDK（purchases_flutter）を利用します。

送信される項目 内容
App User ID 最初は端末の installationId（UUID）。AIチケットを初めて購入するときに、AIアカウントの利用者IDへ切り替えます（AIからログアウトしても戻しません）
購入状態 StoreKit 経由のトランザクション情報、entitlement の有無
端末・SDK 情報 RevenueCat SDK がサービス提供に必要な技術情報（詳細は RevenueCat のポリシーに従う）

意図的に RevenueCat へ送らない情報: タスク内容、氏名、メールアドレス、電話番号、位置情報、写真。

RevenueCat のプライバシーポリシー: https://www.revenuecat.com/privacy

サーバー側の購入確認

AIチケットの加算を一度だけ正しく行うため、開発者のサーバー（AWS Lambda）が RevenueCat API を用い、利用者IDに紐づく購入状態を確認します。購入が完了したのに残数へ反映されていない場合は、アプリの起動時・ログイン後・「購入したチケットを確認」の操作時に、その利用者IDの購入履歴だけを RevenueCat に問い合わせて照合します。CloudWatch ログには利用者IDの全文・トークン・Apple の識別子を記録しません（利用者IDは先頭の一部のみ）。

購入の復元

  • Pro（非消耗）: アプリ内の「購入情報を復元」から StoreKit / RevenueCat 経由で復元できます。
  • AIチケット / Tip（消耗）: 消耗品のため復元できません。AIチケットの残数はAIアカウントごとにサーバーで管理するため、同じ Apple アカウントでログインすれば別の端末でも使えます。
  • AIチケットの購入で App User ID が切り替わった後に Pro の表示が消えた場合は、「購入情報を復元」を実行してください。

5. その他の第三者サービス（分析・広告）

現行バージョン（V1）では、以下の 分析・広告 SDK は組み込んでいません。

  • PostHog、Google Analytics、Firebase Analytics 等の行動分析
  • 広告ネットワーク

将来導入する場合は、本ポリシーを更新し、アプリ内で告知します。

6. データの削除

  • 端末内データ: アプリを削除すると、端末内の SQLite データは OS の仕様に従って削除されます。
  • AIアカウントの削除（アプリ内）: 設定（ポモドーロ通知 → アプリ情報 →「AIアカウント」）から削除できます。削除の前に、未使用のAIチケットの数、削除すると失効して元に戻せないこと、Apple への返金申請の方法を表示し、明示的な同意と Apple での再認証を求めます。
  • 削除すると、Apple の識別子と利用者IDの対応、ログイン情報（セッション・トークン）、AIの無料枠の記録（当月・過去月）、未使用のAIチケットの残数を消去し、Sign in with Apple の許可を Apple 側で取り消します。
  • 同じ購入が二重に加算されないよう、購入の取引IDから作った識別キーだけをサーバーに残します。所有者・商品・残数・日時などは残しません。
  • 購入したのに加算されていないAIチケットがあった場合も、削除後は回復できません。
  • 削除が途中で止まった場合は、完了とは表示せず、Apple での再認証で続けられます。
  • 端末に残っている「反映を確認中のAIチケット購入」の記録も消去します。
  • タスクなどの端末内データと、Pro の App Store 購入は削除されません。
  • 削除後にもう一度ログインすると、新しいAIアカウントになり、削除前の残数は戻りません。
  • 外部 AI データ: Anthropic 側の保持期間経過後に削除されます。個別削除要求は問い合わせ先までご連絡ください（対応可否は Anthropic のポリシーに依存します）。
  • サーバーのログ: 開発者のサーバーのログ（AWS CloudWatch Logs）は30日で自動的に削除されます。ログには、AIに送ったテキスト、トークン、Apple の識別子、取引IDや利用者IDの全文を記録しない設計にしています（件数・理由・IDの先頭の一部だけを記録します。予期しない障害のときは、原因調査のためのエラー情報を記録します）。AIアカウントを削除しても、削除前のログは30日が過ぎるまで残ります。
  • サーバーのバックアップ: サーバーのデータベース（Amazon DynamoDB）のバックアップ（ポイントインタイムリカバリ・手動バックアップ）は取得していません。削除したデータがバックアップから戻ることはありません。
  • 課金データ: 購入履歴は Apple および RevenueCat 側に保持されます。RevenueCat 側データの削除要求は問い合わせ先までご連絡ください（対応可否は RevenueCat のポリシーに依存します）。

7. セキュリティ

  • Anthropic API キーは アプリに埋め込まず、AWS Secrets Manager でサーバー側のみが保持します。
  • アプリに埋め込まれるのは、サーバーの入口で使う接続用のキーだけです。AI 機能はこれに加えて、AIアカウントのアクセス用トークンでの本人確認を必須にしています。
  • Sign in with Apple の秘密鍵はアプリに含めず、AWS Secrets Manager でサーバー側のみが保持します。
  • 通信は HTTPS を使用します。
